What I Build

I take systems from schema to production and stay with them after launch. Most of this year went into two AI platforms under NDA — one live, one built end to end — so the work is described here by what it does, not by whose logo is on it. The engineering is written up in full →

Multi-tenant & regulated systems

Row-level security on every tenant-scoped table, append-only audit, capability grants instead of guessable URLs, and residency gates that survive a change of cloud. The work that decides whether a platform can safely hold someone else's customers.

  • PostgreSQL
  • RLS
  • Audit triggers

AI-integrated products

Agent graphs, retrieval across vector and graph stores, real-time voice, and human approval gates on anything the model isn't allowed to get wrong. Metered per tenant, evaluated against rubrics rather than a vibe check.

  • Claude SDK
  • LangGraph
  • pgvector

Platform & infrastructure

Containers, infrastructure as code, and CI that gates a merge on typecheck, lint, tests, secret scanning and static analysis. I own the path from a commit to a running service, including the unglamorous half of a launch.

  • Terraform
  • Docker
  • GitHub Actions

Interfaces that hold up

Data-dense operator consoles, bilingual English/Arabic with genuine right-to-left, installable PWAs, motion and 3D. Built to stay readable for whoever picks it up after me.

  • React 19
  • Next.js 16
  • TypeScript
