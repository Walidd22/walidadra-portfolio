What I Build

I take systems from schema to production and stay with them after launch: two online stores, a bilingual restaurant menu, my own AI video pipeline, and the interface of a live trading platform. Each one is named below and, where it is public, linked. The engineering is written up in full →

Commerce that holds up under load

Checkout that can't oversell: stock decremented conditionally inside one transaction, row locks on promo codes, catalogue reads cached and invalidated by tag. Nightly encrypted backups, restored to prove they work.

  • PostgreSQL
  • Payload 3
  • Next.js 16

Edge & serverless deployments

Next.js on Cloudflare Workers with Hyperdrive, R2, D1 and Durable Objects, inside a 128 MB memory limit. When the image library didn't fit, I wrote a WebAssembly resize kernel that did.

  • Cloudflare Workers
  • OpenNext
  • WebAssembly

AI-integrated products

A pipeline from script to voice to edited video to a published post, on the Claude API, ElevenLabs and ffmpeg. SSRF and CSRF guards on the routes that act for a user, and about 1,300 tests in CI.

  • Claude API
  • ElevenLabs
  • n8n

Interfaces that hold up

Light and dark themes on CSS variables, mobile layouts for live trading charts, English and Arabic with real right-to-left, and pages tested against WCAG 2.2 AA. Built to stay readable for whoever picks it up after me.

  • React
  • Next.js 16
  • TypeScript

Trendeall — E-commerce Platform

An online store on Next.js 16, Payload 3 and Neon Postgres. Checkout can't oversell: stock is decremented conditionally inside one transaction, and promo codes are row-locked. An outage from uncached catalogue reads (5 GB of egress in 12 days) was fixed with a tag-invalidated cache and ISR.

Full-stack — schema, checkout, caching, backups
