My Story

I'm a full-stack developer from Tripoli, Lebanon. I didn't take a traditional path — I built one. Here's how I got from no internet tutorials in Arabic to shipping real products for real people.

  1. Origin Tripoli, Lebanon

    Where it started

    Grew up in Tripoli. No bootcamps, no visible path into software. Picked up a laptop, opened YouTube, and started typing HTML into a file to see what happened. That first <h1> showing up in a browser was the hook.

  2. Self-taught 1,000+ hours

    Learning by breaking things

    HTML → CSS → JavaScript → React. Built things, broke them, read the errors, googled the errors, built them again. No instructor, no curriculum — just docs, open-source repos, and a lot of stubbornness. That muscle is the one I rely on most today.

  3. First role Telecloud internship

    First production code

    Joined Telecloud as an intern. First time seeing how software actually ships — code review, git flow, deploy pipelines, real users on the other end of a bug. The gap between "works on my machine" and "works in production" became the thing I cared most about closing.

  4. 3 months ArisAI — with Ghadi

    Shipping at real scale

    Joined an AI trading platform mid-build and shipped ~80% of the frontend in three months — 15+ pages including real-time chat, signal rooms, trading dashboards, and the content engine. React, TypeScript, Socket.io against a NestJS backend. First time I owned product-critical surfaces under deadline pressure.

  5. Solo build MyPizza — myypizza.com

    End-to-end, alone

    Built a full restaurant ordering platform solo — auth, menus, cart, payments, admin dashboard, push notifications, gamification, dual currency, PWA, Redis caching. Next.js 16 + Supabase + 10+ integrated systems. The project that made me confident I could ship anything end-to-end.

  6. Now WebRift + AI Content Studio

    Building, teaching, compounding

    Turned the work into WebRift — a small agency where I build production apps for founders. In parallel I'm running an AI Content Studio I built from scratch (16 dashboards, 14 APIs, 81-node knowledge graph, Neo4j + n8n) to document the craft. The whole site you're on right now is part of that loop: build, ship, teach, repeat.
